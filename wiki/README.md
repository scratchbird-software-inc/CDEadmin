# ScratchRobin wiki source

These Markdown files are the reviewed source for the ScratchRobin GitHub wiki.
The application repository retains them so documentation changes can be reviewed
and tested with the code that changes behavior. GitHub serves its wiki from a
separate Git repository; merging these files into CDEadmin does not, by itself,
publish that wiki. After its initial Home page exists, synchronize the files to
`scratchbird-software-inc/CDEadmin.wiki.git` on its default branch. Keep this
directory as the source of truth and do not edit the published copy without
bringing the change back here.

The canonical detailed contracts remain in `docs/en_US/`. This wiki is a
task-oriented guide, not a substitute for exact provider gates or the dated
implementation status.
