WHAT'S IN THE WORKBENCH

Shared controls, native behavior.

The interface reuses forms where that helps, but object types, transactions, maintenance and SQL grammar follow the selected engine.

01 / EXPLORE

Native object navigation

Move from engine to endpoint to database and its actual objects. Context actions and property forms are scoped to the selected provider.

02 / QUERY

Connected SQL workspace

Select an active connection by engine and target, inspect bounded results and use the diagnostics and transaction controls that connection supports.

03 / DESIGN

DDN design exchange

Capture metadata into diagrams, compare saved and live designs, then review qualified native changes before applying them.

04 / OBSERVE

Display-only dashboards

Read native metrics from independent monitoring connections. Layout editing belongs in a separate authorized DDN editor.

A CONNECTED FAMILY

Each mark has its own job.

The family shares a bird-and-wing visual language, while each project keeps a distinct identity. These icons come from the named groups in the owner’s Inkscape artwork.

ScratchRobin

The bird above a database and connected nodes identifies this multi-engine workbench.

ScratchBird

The bird on the database cylinder identifies the database engine.

DDN

The layered wing mark belongs to Diagram Design Notation and its free viewer and designer.

ScratchWeaver

The full bird-and-network mark identifies the commercial diagramming suite that sponsors DDN.

The open-source wing

The open-source mark is derived from the wing of the commercial ScratchBird logo. On dark backgrounds, the blue and white artwork is exchanged: blue becomes white and white becomes blue.
