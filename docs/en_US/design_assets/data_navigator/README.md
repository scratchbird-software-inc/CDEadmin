# Data Navigator visual review assets

The owning specification is [data_navigator_surfaces.rst](../../data_navigator_surfaces.rst).
Open [index.html](index.html) for the self-contained review gallery.

These are historical fixture-based captures and compositions from source revision
`fbee98616cd9cadfb6b21c103bf077a85b141cbf`, before the shared-component implementation.
Current/proposed captions describe that snapshot. Proposals are not blanket approval;
the specification records approved requirements, open decisions and current status.
Images show fixture data, not operator databases. They are documentation assets,
not runtime icons or native-engine qualification evidence.

Only the review galleries, their images, captions and findings are retained here.
Build output, browser profiles, external icon inputs and temporary capture paths
are excluded. `assets.json` records project-relative filenames and SHA-256 hashes.
